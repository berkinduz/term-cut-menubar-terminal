Window controls, easier to find.

- Switch between Compact and Drop-down from **More options (⋯) → Window Mode**, with a checkmark beside the current mode.
- Switching modes keeps your tabs, split panes, and running commands open.
- Added illustrated product previews to the README, showing menu bar access, the drop-down terminal, split panes, and customization settings.

Requires macOS 13 or later. Supports Apple silicon and Intel.

This build is ad-hoc signed, without Apple notarization. macOS may require approval in System Settings → Privacy & Security on first launch.

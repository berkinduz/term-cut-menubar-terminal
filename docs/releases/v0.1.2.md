Command status, quietly visible.

- Added small status dots to the menu bar icon, tab icons, and split panes: green for ready, yellow for a running command, red for a nonzero exit status.
- Failed sessions take priority in the menu bar, even in hidden tabs.
- Added automatic command tracking for top-level zsh login shells, while preserving the user's startup files.
- Unknown activity and ended sessions use gray. Other shells, nested shells, interactive SSH sessions, and background jobs are not individually tracked.

Requires macOS 13 or later. Supports Apple silicon and Intel.

This build is ad-hoc signed, without Apple notarization. macOS may require approval in System Settings → Privacy & Security on first launch.
